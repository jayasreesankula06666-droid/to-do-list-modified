# Student To-Do List — From Date to To Date

A beginner-friendly HTML, CSS, and JavaScript student project.

## Features
- Enter a task name.
- Choose a **From date** and **To date**.
- Displays the weekday with each date (for example, Monday, 26 October 2026).
- Prevents the To date from being earlier than the From date.
- Shows when each task was added.
- Mark tasks completed or delete them.
- Saves tasks in browser `localStorage`.

## Run locally
1. Extract the ZIP.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a browser.

## Publish with GitHub Pages
1. Upload all files to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, branch `main`, folder `/(root)`, and click **Save**.
4. Wait for GitHub Pages to publish your site.

Tasks are stored in this browser on this device; they are not synced across devices.
